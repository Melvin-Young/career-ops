# Career-Ops owns canonical career evidence

Career-Ops will be the sole active source of truth for Career Evidence and application generation. Verified evidence and writing preferences from the existing external `Skill_Corpus` will be imported into the protected Career-Ops user layer with provenance and confirmation, while the original corpus remains a historical archive; the systems will not use bidirectional synchronization because two writable evidence stores would create factual and stylistic drift.
